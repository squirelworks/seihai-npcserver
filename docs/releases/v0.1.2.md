A maintenance release of **seihai-npcserver**: it is now built on seihai-core v0.0.16 (was v0.0.11), the same core seihai-gserver moves to for per-client script delivery (seihai-gserver#45).

## What changed

- seihai-core `v0.0.11` → `v0.0.16`. The NPC-server's own code did not need changes; the scripting engine picks up the core fixes from v0.0.12 to v0.0.16.
- One seihai-core in seihai-gserver's lock file again: the gserver's NC test hands NPC-server types built on core to the gserver's core, so both must use the same tag.

## Tested with

- `cargo test` (all loopback tests against the stand-in gserver) and `cargo clippy --all-targets -- -D warnings` on Linux.

## Download and run

Pick the archive for your system: Linux x86_64, Windows x86_64, macOS Intel (x86_64) or macOS Apple Silicon (aarch64). Most setups let seihai-gserver start it (`npcserver = auto`). To run it yourself:

```
seihai-npcserver --gserver 127.0.0.1:14810 --token-file npcserver-token.txt --world path/to/world
```

On macOS, the first start may need right-click → Open, because the build is not signed.
