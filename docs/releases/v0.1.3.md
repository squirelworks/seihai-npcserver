A release of **seihai-npcserver**, built on seihai-core v0.8.0, with the NC edit and persistence fixes since v0.1.1. (`0.1.2` was set in `Cargo.toml` but never tagged; its notes stay in `v0.1.2.md` for the record, and everything since v0.1.1 is here.)

## What changed

- Built on seihai-core **v0.8.0** (was v0.6.3 at v0.1.1, v0.7.2 on main): NewWorld beta 1 and 2 as real versions, the version-token/profile audit, the PLO_FILE mod time for 2.05 and the NewWorld betas, and the GS2 compiler and executor work in 0.8.0. Same core as seihai-gserver 0.2.0, which hands NPC-server types to its own core.
- **NC script edits** replace the last effective script block in an NPC file, matching both parsers, so a live edit survives a fresh load. Earlier blocks and other fields are kept.
- **NC warps** update the position fields after script blocks as well as before them, so an NPC file keeps the live location on reload.
- **GANI attributes** set by `setcharprop #P1` to `#P30` are saved in a `.txt.attrs` sidecar and restored into the runtime, NC readback and `NPC_ADDED` replay. NPC source files are unchanged. Partial #49: native NC attribute editing is still open.
- Write-failure, retry and reload tests for NC script sets and warps in both NPC file formats.
- Bounded fuzz targets for the NPC link frame and message decoders.
- The release has a `SHA256SUMS` beside the archives.

## Tested with

- `cargo test` (loopback tests against the stand-in gserver) and `cargo clippy --all-targets -- -D warnings` on Linux and Windows in CI.

## Download and run

Pick the archive for your system: Linux x86_64, Windows x86_64, macOS Intel (x86_64) or macOS Apple Silicon (aarch64), and check it against `SHA256SUMS`. Most setups let seihai-gserver start it (`npcserver = auto`). To run it yourself:

```
seihai-npcserver --gserver 127.0.0.1:14810 --token-file npcserver-token.txt --world path/to/world
```

On macOS, the first start may need right-click → Open, because the build is not signed.
