The first release of **seihai-npcserver**, the Seihai project's Graal NPC-server. It is a separate program that logs into seihai-gserver and runs server-side NPC scripts (GS1). It is written from scratch in Rust (MIT or Apache-2.0).

## What it does

- **The NPC-server link** to seihai-gserver (link version 1, specified in `PROTOCOL.md`), authenticated with a shared token. With `npcserver = auto`, the gserver starts the NPC-server itself.
- **Loads `<world>/npcs`** once it has the gserver's level list, and runs each level's server-side scripts with the GS1 engine from seihai-core: `created`, `timeout`, `playerenters`, `playerleaves`, PMs to NPCs and `triggeraction`.
- **Sends the results back to the gserver:**
  - NPC props and `showcharacter`;
  - player props, including rupees, darts and bombs;
  - `setlevel2` warps, PMs (`say2`) and weapon grants (`toweapons`, `addweapon`);
  - server flags and trigger actions;
  - sounds (`play`, `playlooped`, `play2`, `stopsound`, `stopmidi`);
  - `setshape`.
- A stand-in gserver (`cargo run --example mock_gserver`) for trying it without a real one.

## Tested with

- Loopback tests against the stand-in gserver for every message above.
- seihai-gserver's own NPC-server link tests.

## Not in this release

- What has no link message yet is logged once and skipped: `sendtoserver`, and the player variables `playerswordpower`, `playershieldpower` and `playerhp`, and the selected weapon.
- Milestone 3, a sample world tested with real clients, comes in v0.2.0 once seihai-gserver's world is further along.

## Download and run

Pick the archive for your system: Linux x86_64, Windows x86_64, macOS Intel (x86_64) or macOS Apple Silicon (aarch64). Most setups let seihai-gserver start it (`npcserver = auto`). To run it yourself:

```
seihai-npcserver --gserver 127.0.0.1:14810 --token-file npcserver-token.txt --world path/to/world
```

On macOS, the first start may need right-click → Open, because the build is not signed.
